# Bundled typefaces

Both files are variable-weight Latin subsets, byte-identical to the ones
buildforge.top serves, and are bundled so this UI keeps its typeface with no
network request: the app is local-first and is expected to work offline.

- `host-grotesk.woff2` — Host Grotesk, SIL Open Font License 1.1
- `jetbrains-mono.woff2` — JetBrains Mono, SIL Open Font License 1.1

The OFL permits bundling and redistribution as part of a larger work. Neither
font is sold, and neither is offered here on its own. Full licence text:
https://openfontlicense.org
